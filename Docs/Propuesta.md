# Plataforma de gestión para venta de vehículos por consignación

## Tema propuesto

Sistema para administrar inventario, leads, publicaciones, citas y seguimiento de vehículos en un negocio de venta de autos por consignación.

## Problema real

Un negocio de consignación maneja vehículos que pueden estar en local o con sus dueños, publicaciones en varias plataformas, fotos en Drive, contactos por WhatsApp, citas con compradores y cambios de precio. Si todo se maneja manualmente, se pierde control, se duplican datos y se responde tarde a clientes.

## Stakeholders

Dueño del negocio, vendedores, clientes que venden carros, compradores, encargado de redes sociales, administrador financiero.

## Por qué sirve para el proyecto

Tiene varios subsistemas claros: inventario, publicaciones externas, gestión de leads, agenda, notificaciones, archivos/fotos, reportes y pagos/comisiones. También permite integrar WhatsApp Business, Google Calendar, Google Drive, Facebook Marketplace, CR Autos o Encuentra24.

## Atributos de calidad

- Disponibilidad
- Integridad de datos
- Usabilidad
- Interoperabilidad
- Escalabilidad moderada
